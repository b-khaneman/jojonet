آموزش نصب و راه‌اندازی JojoNet v1.6.0
=====================================

دو فایل کنار هم:
  1) JojoNet-v1.6.0-full.zip
  2) همین راهنما

نصب کامل (اسکریپت تانل + پنل وب) با یک دستور است.


۱) کپی زیپ روی سرور
--------------------
از ویندوز (PowerShell):

  scp JojoNet-v1.6.0-full.zip root@IP_سرور:/root/


۲) نصب با یک دستور
------------------
روی سرور لینوکس (Ubuntu / Debian):

  apt-get update -qq && apt-get install -y unzip && unzip -o /root/JojoNet-v1.6.0-full.zip -d /root/jojonet && bash /root/jojonet/install-one.sh

اگر unzip از قبل نصب است:

  unzip -o /root/JojoNet-v1.6.0-full.zip -d /root/jojonet && bash /root/jojonet/install-one.sh

این دستور هم اسکریپت `jojonet` را نصب می‌کند و هم پنل وب را بالا می‌آورد.

پورت پیش‌فرض پنل: 2053 (HTTPS)
پورت دیگر:

  bash /root/jojonet/install-one.sh --port 8443

گواهی معتبر روی دامنه (به‌جای گواهی خودامضا):

  bash /root/jojonet/install-one.sh --domain panel.example.com --email you@example.com

فقط اسکریپت تانل، بدون پنل:

  unzip -o /root/JojoNet-v1.6.0-full.zip -d /root/jojonet && bash /root/jojonet/setup.sh script


۳) اشتراک از پنل (به‌جای کلید JN1)
----------------------------------
فروش از حساب پنل است، نه کلید لایسنس. مالک پنل در تب «مدیریت» مشتری می‌سازد و سقف/روز اشتراک می‌گذارد.

دستورهای قدیمی `jojonet --activate` و `--license` هنوز هستند تا نصب‌های قبلی خطا ندهند، ولی برای کار تانل لازم نیستند.


۴) بعد از نصب پنل
-----------------
آخر خروجی نصب را بخوان. آدرس پنل و (در نصب اول) نام کاربری و رمز مدیر همان‌جا چاپ می‌شود. همان لحظه ذخیره کن؛ رمز دوباره نشان داده نمی‌شود.

دستورهای کمکی:

  jojonet --version
  jojonet-panel url
  jojonet-panel status
  jojonet-panel set-admin

مرورگر را فقط با آدرسی باز کن که این دستور چاپ می‌کند:

  sudo jojonet-panel url

پنل با IP خالی باز نمی‌شود. آدرس حتماً یک مسیر مخفی دارد.
مسیر پیش‌فرض:

  https://IP:PORT/jojonet-panel-entry/

اگر پورت پنل ۸۰ باشد، باز هم آدرس https است و پورت را بنویس:

  https://IP:80/jojonet-panel-entry/

`http://IP` و `https://IP` (که یعنی پورت ۴۴۳) پنل را نشان نمی‌دهند.
گواهی پیش‌فرض خودامضا است؛ مرورگر هشدار امنیتی نشان می‌دهد — تأیید کن و ادامه بده.
مسیر و پورت را بعداً از داخل پنل، تب مدیریت، می‌توانی عوض کنی.


۵) راه‌اندازی پنل
-----------------
1. با کاربر و رمزی که نصب چاپ کرد وارد شو.
2. سرور ایران و سرور خارج را اضافه کن (IP، پورت SSH، رمز یا کلید).
3. روی هر سرور «تست اتصال» و بعد «نصب» را بزن تا jojonet روی آن نصب شود.
4. از تب تانل‌ها نوع تانل را بساز و مشخص کن کاربران به سرور ایران وصل می‌شوند (تانل ایران → خارج) یا به سرور خارج (تانل خارج → ایران). برای DNSTT و ICMP اگر سرور ایران نداری، گزینه «فقط سرور خارج» را بزن. رله تک‌سرور را روی ایران یا خارج می‌توانی بگذاری.

ترتیب دستی از خط فرمان (بدون پنل): اول سرور خارج، بعد ایران.

  خارج:   jojonet --wg IP_ایران
  ایران:  jojonet --wg IP_خارج

برای سرور ایران‌اکسس از پنل حالت «Xray Reverse» را بزن، یا:

  خارج:   jojonet --xray-reverse IP_ایران
  ایران:  jojonet --xray-reverse IP_خارج


۶) حالت‌های تانل (خلاصه)
------------------------
  GRE / WireGuard / Hysteria2 / TUN-TCP / Paqet / VXLAN
  WireGuard داخل ICMP یا FakeTCP
  Rathole و Wstunnel (ریورس)
  Xray Dokodemo-door و Xray Reverse
  6to4 / GRE6 / IPIP6
  Spoof Tunnel
  رله تک‌سرور: iptables / GOST / HAProxy / Socat / Xray


۷) اگر چیزی بالا نیامد
----------------------
  sudo jojonet-panel status
  sudo jojonet-panel url
  sudo jojonet-panel logs
  sudo journalctl -u jojonet-panel -n 40 --no-pager
  sudo journalctl -u jojonet-panel.socket -n 20 --no-pager
  jojonet --status

فایروال سرور و پنل ابری باید همان پورت پنل را باز بگذارد (پیش‌فرض 2053/tcp).
اگر پورت را ۸۰ گذاشتی، در مرورگر https://IP:80/jojonet-panel-entry/ را باز کن، نه http.


حذف
---
  jojonet-uninstall
  jojonet-panel uninstall
  jojonet-panel uninstall --purge    # همراه با داده و رمز پنل
